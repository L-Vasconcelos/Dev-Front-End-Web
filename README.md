# Desenvolvimento Front-End para Web — Instituto Semear

Projeto da disciplina **Desenvolvimento Front-End para Web** (CST em Análise e
Desenvolvimento de Sistemas). Site de uma ONG fictícia, o Instituto Semear,
evoluído ao longo das Experiências Práticas.

| Etapa | Foco | Versão |
|---|---|---|
| Experiência Prática 1 | HTML5 semântico, formulários, acessibilidade, validação W3C | tag `ep1-entregue` |
| Experiência Prática 2 | CSS3: design system, Grid, Flexbox, responsividade, componentes | concluída |
| Experiência Prática 4 | Git/GitFlow, acessibilidade WCAG 2.1, build e deploy | em andamento |

## Estrutura

```
site-ong/     código do site (abrir site-ong/index.html no navegador)
```

Detalhes técnicos em [`site-ong/README.md`](site-ong/README.md).
